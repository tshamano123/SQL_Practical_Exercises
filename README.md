# Practical Exercises README

## Overview

This repository contains practical data analytics exercises completed using different datasets and cloud-based data platforms. The exercises focused on data cleaning, data exploration, querying, analysis, and generating insights from real-world business datasets.

The practical work was completed using:

* [Databricks](https://www.databricks.com?utm_source=chatgpt.com)
* [Google BigQuery](https://cloud.google.com/bigquery?utm_source=chatgpt.com)

These exercises helped strengthen skills in SQL, cloud data analytics, and business intelligence.

---

## Datasets Used

### 1. Bright Coffee Shop Sales Dataset

This dataset was used to analyze coffee shop sales performance and customer purchasing behavior.

#### Key Tasks Performed

* Data cleaning and preprocessing
* Sales analysis
* Revenue calculations
* Customer transaction analysis
* Product performance evaluation
* Aggregations and filtering using SQL queries
* Dashboard preparation

#### Skills Applied

* SQL queries
* Data aggregation
* Filtering and sorting
